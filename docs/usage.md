# AWS PostgreSQL Database (RDS)

Creates a managed PostgreSQL database with Amazon RDS in a private network. The admin password is generated by RDS and stored in AWS Secrets Manager. It never appears in the code or the state.

Use it when an application or a demo needs a secure PostgreSQL database.

## What gets created

- A VPC with two private subnets and no internet access
- A security group that allows port 5432 only from inside the VPC
- The RDS PostgreSQL instance with a parameter group. A standby in a second zone is optional
- The admin password in Secrets Manager
- Database logs in CloudWatch, enhanced monitoring and VPC flow logs

## Before you start

- A workflow with an AWS cloud connector for the target account
- Permissions to create VPC, RDS, Secrets Manager, IAM and CloudWatch Logs resources
- A plan for how clients reach the database: they must run inside this VPC

## Form fields

| Field | What it does | Default |
|---|---|---|
| Name prefix | Prefix for all resource names. 2 to 16 lowercase letters, digits or hyphens, starting with a letter | `demo` |
| Region | AWS region | `eu-central-1` |
| Tags | Extra tags added to all resources | none |
| VPC cidr | IP range of the new network | `10.0.0.0/16` |
| Engine version | PostgreSQL major version | `17` |
| Instance class | Size of the database server | `db.t4g.micro` |
| Allocated storage | Storage in GiB | `20` |
| Database name | Name of the first database | `app` |
| Master username | Name of the admin user | `dbadmin` |
| Multi az | Runs a standby in a second zone for high availability | off |
| Backup retention days | How many days automated backups are kept | `7` |
| Deletion protection | Protects the database from deletion. Keep it off for demos | off |
| Skip final snapshot | Skips the last backup when the database is deleted | on |
| Log retention days | How long database logs and flow logs are kept | `90` |

## After the run

The workflow outputs show:

- `endpoint`, `port` and `database_name`: the connection details
- `master_username` and `master_user_secret_arn`: read the password with `aws secretsmanager get-secret-value --secret-id <master_user_secret_arn> --query SecretString --output text`
- `vpc_id` and `private_subnet_ids`: deploy your clients here

Creating the database takes about 5 to 10 minutes.

## Security defaults

- Not reachable from the internet, only from inside the VPC
- Storage is encrypted and SSL connections are enforced
- IAM database authentication is enabled
- Automated backups and minor version upgrades are on
- Connections and disconnections are logged

## Cost and cleanup

The database and its storage are billed per hour, also when idle. Secrets Manager bills per secret and month. Destroy the resources from the workflow when the demo is over. With the defaults, no final backup is kept.

## Limits

- Single instance unless you switch on Multi az
- No access from outside the VPC
